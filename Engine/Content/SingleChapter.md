# 单章七站体验内容

整局入口配对读取 `SingleChapterBattle.xml` 与 `SingleChapterAdventure.xml`。这是一套独立体验配置，保留原标准单局和三章配置供原测试与场景使用。

单章地图和经济循环沿用主案 revision 3869 / 3873，基础休息回血为 **20**；守门人与暴怒现接入 2026-10-22 确认的新版战斗规则。不接入推币机。

## 路线与数值

```text
小怪一 → 宝箱 → 小怪二 → 商店一 / 休息一 → 守门人 → 商店二 / 休息二 → 暴怒
```

两个补给位置各自二选一，选择后汇合到同一主线。XML 共九个节点定义，每条实际路线均为七站、一个章节。

| 站点 | 配置 ID | 遭遇 / 收益 |
| --- | --- | --- |
| 小怪一 | `battle-1` | `single-chapter-battle-1`；10 回合；50 金币 |
| 宝箱 | `chest` | 进场自动开箱；100 金币和一件本局未获得的道具 |
| 小怪二 | `battle-2` | `single-chapter-battle-2`；10 回合；血量与攻击为首战的 1.25 倍；60 金币 |
| 补给一 | `shop-1` / `rest-1` | 商店或休息 |
| 守门人 | `elite` | `single-chapter-gatekeeper`；20 回合；800 金币 |
| 补给二 | `shop-2` / `rest-2` | 商店或休息 |
| 暴怒 | `boss` | `single-chapter-wrath`；20 回合；胜利完成本局 |

血量与伤害取整沿用战斗引擎向下取整。小怪血量分别为 450 / 562，交替攻击为 40、65 / 50、81。两场小怪均仅进行攻击，无护盾或特殊机制。各场达到回合上限失败。

起始金币沿用 30，遗物栏容量沿用 5，牌库最低 5、最高 128；这些都是 `AdventureContent` 根配置。当前仅保留已实现的愚者开局天赋，最大生命 +20%。未将旧三章的通关解锁占位天赋带入体验版。

## 品质与经济

十二件道具沿用 `final.xml` 定义的效果和售出价格，显式添加 `quality`，与实例的升级 `Level` 无关。

| 品质 | 道具定义 ID | 商店买入价 |
| --- | --- | --- |
| 0 | 10001、10002 | 10 |
| 1 | 11002、11003、11004 | 20 |
| 2 | 12001 | 30 |
| 3 | 13001、13002、13003、13004 | 50 |
| 4 | 14001 | 100 |
| 5 | 15001 | 每个报价独立随机 50–200 |

空 `<Shop />` 使用全部十二件道具作为候选池。商店每次进场生成四个报价，已持有的唯一道具不入池，非唯一道具可以占据多个不同报价位。购买后该报价售罄，不补货；预览、页面重开和恢复存档都不会重抽。

三个改牌服务分别计次：删牌 45、复制牌 20、改花色 30。第 1–3 次维持基础价格，第 4–10 次逐次 ×1.1，第 11 次开始逐次 ×1.07，内部保留小数，支付与显示价格四舍五入。

休息进场固定恢复 20 生命，不超过上限。玩家可直接离开，或免费抽奖一次。高阶道具增减、两件低阶道具、金币增减三类结果各占三分之一。高阶为品质 3–4，低阶为品质 0–2，金币为 0–500；金币余额最低为零。道具奖励满栏时进入待领取队列，逐件选择替换一个已持有实例或放弃，处理完后才能离开。

## 精英与暴怒规则

七站的普通敌人、玩家、牌型、道具、成长与经济仍保留既有数值。守门人和暴怒使用当前标准 `.21.xml` 中已经验证的新版规则，保留 `summoner` / `wrath` 模板 ID 和 `single-chapter-gatekeeper` / `single-chapter-wrath` 遭遇 ID，宿主的场景及美术映射继续使用原入口。

- 守门人为 **400 生命**的流血精英，初始攻击 **8**，全场每轮增加 **10**；交替执行半攻伤害后叠加 3 层流血、一次全攻普攻。流血每层使敌方主攻击承伤增加 50%，施加者行动结束减 1 层；新流血在本次伤害后施加。没有旧入场护甲或护卫召唤。
- 暴怒本体 **1500 生命**，四饮血手和一束缚手各 **1 生命**。`D = 8 + 5 × 存活手数 + 10 × 成功蓄力次数`；常规顺序为普攻、普攻、龟缩、蓄力。龟缩刷新两次最终免伤，蓄力永久加 10；控制跳过行动时不推进序列或蓄力。
- 五手齐全且本体可行动时，第 5 轮预警、第 6 轮在常规动作后追加 3D 大招，正常下一组为第 11/12 轮；断手或到期无法行动会取消并重新冷却 5 轮。第 12 轮先蓄力再放大招，未受其他修正时伤害为 **189**。
- 手在死亡轮 R 的 **R+8 敌方阶段开始**独立再生，同轮到期全部复活；五手不参与冒险生命倍率，本体沿用现有倍率。手不接受正向加攻或数值护盾。饮血手先结算自己的毒伤，存活且可行动才各治疗本体 5；本体随后结算自己的毒伤。束缚按全场第 5、10、15、20 轮使玩家跳过下一行动窗口，免控可以阻挡，错过不补发。
- 本体死亡即胜利；玩家替死立即中止敌方阶段。完整第 20 轮结算后判负，不消耗替死；护盾沿用玩家回合开始清除。七站不再使用旧五手联动、半血复活或旧 1700 血暴怒。历史标准 XML、旧模板和三章冒险仍保留。

内容指纹随本次接入变化，旧配置生成的存档会按既有恢复规则拒绝加载；本次没有增加存档迁移。

## 验证

从 Unity 仓库根目录执行：

```sh
bash Tools/test-poker-engine.sh SingleChapterContentTests AdventureEconomyTests SingleChapterEnemyRulesTests
```

`SingleChapterContentTests` 保留原四条路线及经济回归：检查节点、品质、回合上限、小怪倍率，并用低生命敌人隔离经济流程，覆盖入场预览、金币发放、固定库存与限购、休息可跳过/只抽一次、永久改牌、每个检查点恢复、七站结束和单次结算。

`SingleChapterEnemyRulesTests` 单独加载真实七站战斗配置，不把目标敌人替换成 1 血夹具：验证精英四轮实际伤害和流血层数、暴怒两组预警/大招与第 12 轮 189 伤害，并沿真实七站路线进入精英/Boss，验证冒险存档恢复后的流血、逐手再生、大招和 20 轮判负。前置无关战斗通过公开管理员入口结束，随机宝箱道具在目标战前清空以隔离数值；20 轮用例只提高测试玩家的生命上限。规则测试不替代 Unity 场景验收。
